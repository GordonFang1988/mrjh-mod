# AVG 诊断导出 v2

2026-10-01，随 1.0.2 发布。导出 schema 为 mrjh-diagnostic-v2。

诊断只读取历史回复、演出快照、当前素材库和舞台状态。它不修改场景分类、游戏位置、存档或命令，不增加模型请求，不根据地名或正文推断场景。

## 读结论

- sceneDiagnosis：优先针对实际正在播放的回合和镜头。scope 和 turnNumber 明确结论对象；confirmed=false 表示仍在加载或缺少证据。
- latestTurn.sourceDiagnosis：最新回合的结构化字段来源结论，可能与正在播放的旧回合不同。
- latestTurn.sourceEvidence：从该回合 rawJson 检查演出场景块或 JSON 字段，并与保存后的字段比较。只导出场景结构、ref、有限正文片段和有界且脱敏的格式错误片段，不导出完整回复。
- playback.sourceEvidence：播放旧回合时另附该回合的来源证据；最新回合不重复附加。
- scenes[].matching：与实际自动匹配共享过滤逻辑，列出导出时素材库的空间、场所体系、功能、主题等候选数量。候选统计没有还原历史地点的风格偏好，也不代表生成当时的素材库。
- playback：播放段落、原日志索引、场景 ref、地点键、资源 ID、图片加载状态和实际尺寸。
- latestTurn.bindingReuse 与 playback.bindingReuse：用该回合之前的历史，展示场景 ID、精确地点键、模型已声明别名查找，已绑定资源列表与结构冲突。它与正式绑定查询共享逻辑；不会把两个近似地名自行判定为同一地点。

## 从新回合开始保存的证据

聊天记录 avgSceneTrace 保存实际构建的请求消息链是否包含完整 AVG 协议、请求时 AVG 开关、协议版本、协议所在消息索引（从 0 开始）、标签解析选项、已绑定列表是否注入及数量，以及解析、正文处理、变量合并和最终回合各阶段的分类/引用数量。开场与普通回合均记录，随已有存档 ZIP 保留。

请求证据只记录客户端消息链的布尔值和索引，不能证明代理或模型服务端接收后如何处理。原始请求、API 配置和密钥不保存到这份证据。

旧回合没有请求证据时 request=null，limitations 明确未知。当前 AVG 开关单独放在 currentSettings，不能用于推断历史请求。旧回合若已保存 rawJson，新导出仍可检查原始字段，因此通常无须完整存档。旧的 v1 导出没有 rawJson 中的字段证据，不能据此认定模型没有输出。

## 可区分的问题

请求缺少 AVG 协议、请求时关闭 AVG、原始回复未含场景字段、场景 JSON 无法读取、结构字段不完整、重复 ref、原始字段被解析器丢弃、字段在后续处理阶段丢失、镜头引用未保留/无法映射、演出快照缺失、当前无兼容素材、选中图包或应用内图片文件缺失、素材库读取失败、浏览器图片加载失败，以及仍在加载。

同地点已有历史绑定、但旧回合尚未保存复用结果时，结论为 scene-existing-binding-not-applied；重新读档可恢复精确匹配的旧空白。原始字段缺失仍另列在 sourceDiagnosis。已有图但地点键不同且无已声明 ID/别名，则显示 no-exact-place-binding 与绑定列表；代码不根据地名猜别名。ID 与地点关联冲突为 scene-binding-conflict。

针对解析器，导出重新解析时使用已记录的标签修复开关；旧回合使用当前默认值并明确请求未知。结构可读取但未提取时附关闭标签修复的对照结果。这是诊断，不改变正式解析结果。模型提供的分类字符串继续保留；不存在对应素材不会被当成语义错误。

如果原始回复本身未含字段，这份证据只证明回复中缺失，不能凭空判断模型内部原因或服务器截断原因。无法恢复历史请求证据的旧回合会保留这个限制。

## 内容和验证

导出沿用人物绑定和近期回合摘要，不导出 API 设置、完整提示词、完整存档和图片字节。自由文本中的常见凭证、签名 URL 参数和嵌入图片数据会脱敏。图包、本地图像可用性只作读取，不下载远程图片。

回归：scripts/avgDiagnosticRegression.mjs、scripts/avgSaveRoundtrip.mjs、既有场景/恢复回归、TypeScript 与生产构建。浏览器演出与导出模态框验证包含当前/历史回合、缺字段/解析后丢失、缺协议、旧回合未知请求、缺本地图包文件、解码失败、无候选和无 ref；验证复制/下载 JSON、桌面和 390 像素手机布局。
