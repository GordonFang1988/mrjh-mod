# 多块演出场景解析修复

## 原因

v1.0.12 用户诊断包含三个完整、可直接读取的演出场景 JSON 块，分别定义 s1 石室、s2 江岸出口、s3 山道密林。23 段正文的镜头引用均已保留，但解析、润色、变量合并和最终存储的场景表始终只有 s1。

标签解析器使用“提取首个标签内容”读取演出场景，遗漏第二、第三块。因而 s2、s3 无法关联地点或分类，尚未进入图库评分就产生未知背景。不是本次模型漏返回场景，也不是图片文件加载失败。

## 修复

- 读取全部演出场景块，兼容场景数组与含“场景”数组的对象。汇总原始条目后统一规范化，跨块重复 ref 仍作为歧义拒绝。
- 读档时只从原始回复补充现有镜头缺少的场景字段，再重建演出。原始回复、已保存对白、润色正文、游戏命令和已有图片不被替换；手工背景继续保留。
- 原始字段不可读、引用有歧义或图片不可读取时不宣称恢复成功。无需请求 LLM 或重新执行命令。
- 诊断增加“部分场景字段未保留”的原因，避免仅因存在 s1 就把场景来源判为完整。

## 验证

回归入口：scripts/avgMultiBlockSceneRegression.mjs。可选参数为本地诊断文件与完整素材清单路径，私有诊断不随代码提交。

覆盖多块/单块等价、数组/对象混用、不可读块、跨块重复引用、思考段排除、标签修复开关、旧存档恢复、缺失文件保护、已有图片与命令保留，以及重复读档幂等。

以用户诊断结构重建回合，使用完整 2230 张场景清单，恢复全部 23 段的三个镜头：s1 保留 ST130，s2 选择 UE438，s3 复用 FR034。诊断只提供截断的正文摘要，本地重建验证不等同于直接操作用户存档。

独立浏览器中复现第 15 段 s3 无图，调用实际读档美术恢复函数后，23 段逐段检查图片解码成功、背景 ID 符合对应镜头；重播与重复恢复通过。第 15 段截图显示山道密林背景。浏览器报告及截图保存在隔离工作目录的 work/playwright/multiblock-scene-2026-10-02，不随代码发布。

生产 TypeScript 检查、12 项相关回归和生产构建通过。未修改用户浏览器数据或调用剧情接口。
