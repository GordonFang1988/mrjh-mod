# 近期 API 性能诊断

## 记录范围

诊断 schema 升级为 mrjh-diagnostic-v3，沿用现有诊断导出入口。API 指标独立于游戏存档，保存在浏览器本地固定长度队列中，最多 60 次文本调用；新增记录淘汰最早记录。刷新后仍能导出已记录指标。游戏导出仅包含最近 10 个有结构化回复的助手回合，以及当前实际播放回合的诊断；不导出完整历史或回档快照。

历史场景绑定查询仍使用完整存档，以保证查找旧地点的正确性；导出的绑定摘要最多 20 条。近期每回合的场景与立绘绑定摘要各最多 20 条，超出时有截断标记。此限制不裁剪游戏存档、剧情上下文或演出。

统一文本客户端记录主剧情、世界演化、规划分析、变量生成、回忆、润色、世界/境界生成、小说拆分和连接测试。其他经过该客户端的调用标为 other。模型列表、图片生成和本地处理未纳入本次文本计时。

## 指标含义

每次逻辑调用有独立 ID，包含实际模型、供应商、目标接口 origin、实际传输 origin（可区分 OpenCode 代理）、输入字符数、消息数、输出上限、开始时间、总耗时与内部自动重试次数/实际等待。每次 HTTP 尝试单独记录：

- headersMs：从本次尝试开始到响应头可读取。
- firstByteMs：首次读取到流式网络数据；心跳可能早于模型输出。
- firstOutputMs：第一个非空模型输出，包括接口单独返回的思考。
- firstReasoningMs / firstContentMs：思考字段与 content 字段首次到达，角色事件、心跳及空增量不算首字。
- generationMs / charsPerSecond：首次至最后输出的接收区间，以及该区间接收的字符均速。单个增量、零间隔或非流式响应不提供速度。
- usage：仅保存接口实际返回的输入、输出和思考 token 数，不估算或将字符数当成 token。
- 状态、HTTP 状态码、错误类别、流式实际状态、输出/思考字符数与结束原因。

调用总耗时包含内部重试等待。任务汇总是近期记录的累计耗时，不能直接当作用户整回合等待，尤其多个任务并发时。工作流自动重跑、手动重试另记一次调用；内部重试与流式降级在同一调用内记录。尚未完成的当前请求标记 live，刷新前留下的 running 记录不是仍在执行的证明。

## 采集与降级

世界演化、规划分析从原非流式改为内部流式采集；仅在完整文本返回后继续原解析和命令应用，未更改任务顺序、模型、提示词或重试策略。其他任务维持原流式设置。

接口拒绝流式时沿用非流式降级；若接口忽略 stream=true 但直接返回合法的完整 JSON 结果，消费已有结果而不重复提交生成。非流式结果没有可观察的首字或生成速度，字段留空，不用响应头或整包收到时间冒充。代理缓冲也会影响客户端接收速度，记录无法直接分解服务端排队、预填充和隐藏思考。

记录是白名单统计量，完整请求/回复、Authorization、API 密钥、URL 用户名/密码、路径与查询参数不入队列。错误只记录类别与状态码。存储不可用时仍在内存中采集并标明限制；诊断与计时故障不应影响 API 请求结果。

## 验证

scripts/apiDiagnosticsRegression.mjs 使用离线请求与可控时钟验证：响应头、心跳首包、思考首字、正文首字、字符速度、实际 usage、非流式结果复用、400 拒绝流式后的兼容降级、401、429 自动重试与等待、中途取消、实际世界/规划调用、请求进行中、100 回合只导出末 10 回合、60 调用上限、刷新后的白名单加载、存储阻断与敏感内容排除。

scripts/apiTransportRegression.mjs 的会话 UUID 检查限定在 OpenCode 会话命名空间，使新增指标存储与原会话验证兼容。私有诊断和离线浏览器测试数据不提交。

生产类型检查、构建、API 传输、AVG 诊断、AVG 开局请求和规划兼容回归通过。真实浏览器调用世界演化与规划分析函数（离线 SSE），验证诊断弹窗、JSON 下载、思考/正文分别计时、实际 usage、100 回合仅导出末 10 回合、刷新后保留记录，以及 390px 窄屏下载入口。未调用真实付费 API；实际慢请求需要更新后重新运行并导出，旧请求无法补算首字。
