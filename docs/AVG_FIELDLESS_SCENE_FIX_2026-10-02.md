# v1.0.7 缺场景字段时的背景恢复

本次诊断中，2230 张场景图已加载，开局请求也包含 AVG 协议，但模型没有返回场景分类或镜头标记。“后院柴房”被保存为未知空间，旧代码提前禁止选图，未进入评分；读档缺图恢复也跳过了未知空间。

模型缺少空间分类、且当前镜头有明确具体地点时，新增独立的近似选图路径：用房间类型搜索同类型素材，再结合已有分类字段、地点与素材标签、场所用途评分。场所名称推得的用途只作为偏好，不能硬排除相近房间。最高分同分集合按地点稳定选择。

原模型 profile 保持原样，近似依据另存 fallback，并用于诊断。完整模型分类、冻结绑定、手动背景与镜头映射继续优先。未映射的镜头不借用最终地点，无法识别具体地点时仍保留中性背景。

读档可恢复此前的自动空白回合，仅在本地图片可读取时应用。保留正文、变量命令、手动中性背景及缺失的冻结图片身份；重复恢复不再修改记录。
