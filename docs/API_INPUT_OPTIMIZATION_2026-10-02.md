## 已落实的行为

| 环节 | 新行为 |
| --- | --- |
| 回忆检索 | 本地最多24候选（默认20，含4条近期保留），只发送这些候选的概括与相关证据节选；语料最多10,000字符 |
| 回忆读取 | 模型结果限定在实际发送的候选编号中；最多5条强回忆、6条弱回忆，主剧情回忆标签总量最多16,000字符；小档案可保留完整原文，大档案明确标注节选 |
| 世界演化 | 构建带原始索引的只读视图，优先到期/临近事件、相关实体、异地事件及女主远端线；历史/地图/建筑仅发有限相关条目 |
| 世界近期事实 | 本回合正文单独发送，近期承接使用最多4条短期记忆；移除正常世界更新的6回合完整正文窗口，开局也减少事实重复 |
| 规划 | 按当前章节/计划、相关NPC、世界事件构建视图；正常工作流采用本回合正文与摘要、前两回合已有摘要；不默认发送完整人物物品表与立绘资源 |
| 小说分解 | 辅助链路详细注入限制实际生效：默认4,000字符，支持500～8,000；运行滑窗、旧快照和树回退均受限；主剧情链路的独立上限策略保留 |
| 世界书 | 第一条、常驻条目也遵守预算；按完整条目选择，预留分组与省略提示空间；超大条目不会绕过预算 |
| 附加资料 | 只注入一份，按完整记录选择；保留事件/约束及其信息可见性的关联，省略时明确标注 |
| 分析协议 | 世界取消16步至少48条、规划取消10步至少30条的长篇固定审计要求；无更新时直接结束，有更新时简述依据后输出命令 |
| 输出预算 | 回忆每请求最多4,096输出tokens，世界/规划最多8,192；尊重用户更小的配置，不修改保存的API配置 |

单位区分：输入预算使用 Unicode 字符，输出使用既有接口 max_tokens 参数。没有估算输入tokens；实际用量仍以提供方 usage 为准。输出上限不保证所有提供方以相同方式限制原生推理。

### 请求总预算

回忆整个请求最多14,000字符，世界演化和规划各最多48,000字符，包含固定规则与动态材料。

先为结构参考、格式与职责预留空间，再给状态和附加资料分配预算。JSON先构建可解析的视图，避免把JSON直接从中间切断；传输层完成角色兼容处理后再次检查实际消息总量。固定必要规则超过预算时不发出请求，不通过截断规则勉强发送。

分块预算目前是工程默认值，没有新增设置页面。

## 状态与写回保护

- 视图中的 "[93]" 表示完整规范化数组的原始第93项；__总数表示完整数组长度。不会将展示顺序重新编号成存档索引。
- 未展示项继续留在存档；禁止修改或删除不可见索引，禁止用局部视图替换缺项数组或上层对象。数字点路径与括号路径按同一索引验证。
- 条件、时间或标识未完整展示时，相关对象的写回会被保留。节选和视图元数据不得写入存档。
- 人物或事件的重复新增会被检查；完整可见旧项允许以“push新项→delete旧项”迁移，不阻断原有续段行为。
- 补丁先修改字段、再追加、最后按原始索引降序删除；验证过实际状态命令处理器更新第93项并保留隐藏项。
- 未完整展示的当前章门禁或待收束事件不能用于切章或清空任务。模型生成的越界命令被过滤。
- 接口明确报告输出达到长度上限时，本次不写回，不为同一次输出限额失败重复请求。标签未闭合的命令输出也拒绝写回。回忆可使用本地候选回退。
- 世界更新仍先完成，规划仍读取世界更新后的状态。

这些保护会使证据不足的更新暂缓，优先保持现有状态。超大、不完整条件不能凭空补成“已满足”。

## 诊断导出

保留最近60次API调用、最近10个助手回合及原有响应头/首字/出字/推理/重试统计。

新增 inputBreakdown：

- budgetChars：本任务字符预算。
- sections：角色兼容合并前各消息的来源量与发送量。
- details：世界、社交、正文、回忆、小说、世界书等数据块的预处理字符量和可用条目数量。
- sourceItems / sentItems / omittedItems：适用块的条目数。

details存在父子关系，且资料可能再受外层附加包预算筛选，不能把所有数字直接相加。最终请求总量以 inputChars 为准。世界书来源统计仅计当前作用域/时间/关键词命中的条目，不包含未命中材料。

不保存提示词正文、NPC姓名、档案原文、返回正文、密钥或完整端点路径；恢复本地记录时也只接受固定块名称和数字字段。旧诊断没有这些分块统计，不能追溯旧请求的具体组成。

## 离线结果

使用三版研究时保存的原版固定提交 bfca81e7bb04ba50fd45b1953462e3fb4409033e 请求函数，以及当前优化后的函数，对同一合成样例捕获实际请求内容。无真实网络调用。

| 样例 | 原版/优化前 | 优化后 | 减少 |
| --- | ---: | ---: | ---: |
| 1,000条回忆的检索语料 | 149,260字符 | 6,534字符 | 95.6% |
| 大世界样例的完整世界请求 | 384,559字符 | 22,563字符 | 94.1% |
| 大世界、100个人物和长正文的规划请求 | 1,705,977字符 | 33,032字符 | 98.1% |

世界样例含150个地点、60条史册、100个事件；原始第93项为异地到期事件，优化后保留且写回正确。规划样例故意包含大量记忆和立绘资源，用于验证增长边界。

这些是合成压力样例，不是用户上一回合的重放，也不是实际提供方token或耗时测量。比例不能直接推广到普通存档。真实速度还受提供方推理、输出速度、代理缓冲和网络重试影响。

## 验证与边界

已通过：

- 辅助输入回归：数量预算、远期线索、原文末尾无标点线索、实际候选ID、隐藏索引、迁移与降序删除、实际状态写回、章节门禁。
- 女主/同人/GPT模式与DeepSeek角色兼容下的最终消息预算。
- 世界书超大首条、小说实时滑窗及快照回退、完整条件与可见性记录选择。
- 输出长度截断与缺失闭合标签的写回拒绝。
- API诊断隐私与恢复、运输与配置复用、开局AVG请求、女主规划回退、NPC稳定命令等相关回归。
- 游戏源目录TypeScript检查与生产构建，发布身份检查通过。

类型检查使用 work/checks/tsconfig.auxiliary.json，继承仓库配置并覆盖游戏源目录。直接遍历仓库的 tsc 会纳入 work 下两份研究克隆而耗尽默认堆，本次未把参考仓库作为游戏代码检查，也未修改原有 tsconfig.json。

尚未验证真实提供方的完整自然回合、实际延迟下降和长期剧情质量；不能以离线通过代替人工游玩。回忆与任务相关性当前采用本地文本匹配和已有时间门槛，没有新增向量服务或额外API。
