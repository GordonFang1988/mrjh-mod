## 存档问题的原因

- 武大郎的专用资源年龄下限为 35，而存档人物年龄为 30，导致此前选中了通用仓秤手。仅修正武大郎这条资源的年龄下限，并在读取旧存档时允许通用自动绑定恢复到兼容的具名资源；手动绑定保持优先。
- 姚二郎实际年龄为 18，视觉年龄字段却为 teen。原匹配把视觉年龄作为硬限制，导致无匹配。实际年龄区间仍为硬限制，视觉年龄改为评分项。
- 该存档未保存场景提示或转场标记，原降级路径显示中性背景。现根据最终地点中的明确地点词推断基础场景类型，本例十字路口匹配城内街道。无法判断的地点仍显示未知，不猜测正文内转场。

- 沉浸模式保留半透明顶部状态栏、行动选项与行动输入。
- 鼠标移至左右边缘展开面板，离开面板范围收起；窄屏可点击边缘入口展开。

- 从最新回合进入沉浸后，新回合完成可继续使用沉浸舞台；打开设置保持当前播放句。
- 右上角新增诊断导出，支持复制与 JSON 下载，包含资源包、人物/场景绑定、匹配候选与实际图片加载状态。使用白名单构建，不导出 API 配置和密钥。
