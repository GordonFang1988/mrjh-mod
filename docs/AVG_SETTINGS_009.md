# AVG 演出设置 009

新增独立的设置 → AVG 演出设置入口，桌面和移动端共用面板。

## 功能

- 立绘大小、左右/上下位置：本机偏好，滑块实时示意，点击保存后通知所有 AVG 舞台。
- 旁白缩小比例、不透明度；保持单人物显示、其他人物发言替换、不灰化的原行为。
- 对白/旁白预览、恢复默认、保存失败反馈。
- 现有场景协议开关、存档美术主题、多次/多 ZIP 导入、包数量与卸载迁移到独立页，复用原存储实现。
- 资源包与存档仍分开；原美术绑定、预制和已有生图优先级不变。

## 验证

2026-10-01：TypeScript noEmit、Vite build、portraitStageRegression 均通过。
