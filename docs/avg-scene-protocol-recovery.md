# 镜头协议容错与旧回合恢复（v1.0.12）

用户诊断来自 v1.0.11：图库 2230 张正常，模型返回了 s1 密道、s2 峡谷、s3 门派前庭三份场景分类，但正文使用 `【镜头 ref="s1"/>` 等混合括号。旧解析只识别 XML 外形，三个标记均进入普通正文，已保存 25 段日志没有任何镜头引用，最终演出为 `no-scene-markers` 和未知场景。选图逻辑在没有镜头对应关系的情况下无法使用这些分类。

## 共享协议层

`sceneProtocol.ts` 统一扫描镜头边界。扫描识别引号范围，兼容中文/半角/全角外括号、弯引号、全角等号和斜线、未加引号的单个引用。引用名中的括号不会提前终止标记。无法读取引用的残缺标记仍形成空引用边界，避免前一个镜头延伸到后文；普通“镜头”字样及 `【镜头】` 标题不视为镜头指令。

标签回复与润色使用同一边界扫描、引用读取；JSON 日志和已保存日志使用同一元数据分离器。分离器保留原日志的说话人及非标记文字，只移除控制标记和由它单独形成的空段。无标记的日志保持原数组引用。

## 旧记录修复

读档使用已保存日志中的标记和该回合明确保存的场景表，不从剧情语义猜测转场，也不重新生成剧情。只有恢复出的引用均有唯一场景映射、身份无冲突、所需图片可读取时才应用。手工最终背景保持原样；已有按镜头冻结的选择继续保留。原始回复、润色前正文和游戏命令保留，重复读档无需再改写。

诊断复用相同扫描器，增加非标准标记计数，并区分“确实没有镜头标记”与“旧解析未识别、当前可恢复的标记”。
