# 功能 API 档案复用

在“API 设置”保存 API 档案，统一填写地址、密钥、接口类型、协议和默认模型。在世界演变、变量生成、规划分析等功能设置中开启原有独立模型开关，再选择已保存的 API 档案即可。每个功能可以另选模型；“跟随主 API 档案”使用当前主档案的连接，也允许保留该功能的模型选择。

覆盖剧情回忆、记忆总结、世界演变、变量计算、规划分析、文章优化、小说分解、文生图、场景生图、词组转化器和 PNG 提炼。旧女主规划、剧情规划入口统一引用规划分析配置。原有开关决定功能是否执行；选择档案不会新增、删减请求或开启功能。图片后端、图片路径和 ComfyUI 工作流继续在图片设置中维护。

接口类型从所选档案继承，可在“API 设置”修改。文本生成继续采用项目现有的 Chat Completions 请求与兼容处理；这次改动没有增加原生 Gemini/Claude 文本协议实现。提示词、剧情、记忆、判定、重试和功能特定输出上限保持原有逻辑。小说分解继续使用 32768 的输出上限。

## 保存与兼容

- 每个功能只保存档案 ID 和模型选择，不复制所选档案的地址或密钥。修改档案连接后，各引用功能同步使用新连接。OpenCode 请求沿用该档案的持久化会话标识与现有代理。
- 获取的模型列表缓存在所属档案，其他引用功能可直接复用。修改档案连接会清除旧列表；尚未完成的旧地址请求不会覆盖新连接的列表。
- 旧独立地址和密钥保留，可选择“旧独立配置（兼容）”继续使用。改选档案后旧字段不参与请求；已有 API 设置导入导出继续有效。
- 删除被引用的档案后，引用 ID 保留，页面提示重新选择。启用的功能不能保存已删除的绑定，也不会自动切换到另一个档案。关闭独立功能时保留原有主 API 回退语义。

数据新增两个可选字段：档案的 `模型列表` 和 `功能模型占位.功能API档案`。绑定键缺失表示保持旧配置，空字符串表示明确跟随当前主档案，其他字符串表示引用具体档案 ID。设置规范化和 IndexedDB 导入导出保留这些字段。

## 验证

`node scripts/apiProfileReuseRegression.mjs` 验证全部功能解析、共享连接修改、接口类型继承、模型选择、旧配置兼容、删除档案处理、开关语义、设置往返、请求体、代理会话及 PNG 工作流。使用合成配置和离线响应，不需要真实密钥。

真实浏览器使用现有设置组件和 IndexedDB，验证档案选择、保存、模型列表共享、功能模型覆盖、刷新恢复、研发设置导入导出和移动端布局。API 响应使用浏览器拦截的离线样本；三个文本功能均通过实际客户端走代理，测试中未发出真实上游请求。
