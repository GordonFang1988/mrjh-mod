# AVG 场景分类职责边界

2026-10-01，随 1.0.1 修复生效。

场景分类由剧情模型通过结构化字段提供。客户端负责读取字段、建立镜头引用、匹配图片和保存演出快照，不判断模型分类的语义是否正确。

- 保留模型提供的分类字符串，按其空间、地域、场所体系、场所功能等字段匹配素材。素材目录继续使用既有分类词表。
- 不比较镜头地点名称与最终游戏地点来否决分类，不使用地名关键词推断或重新生成分类。
- 字段缺失、类型无法读取、引用不存在或定义重复时，仅对应镜头使用中性背景；其他镜头继续播放。
- 模型分类没有对应素材时使用中性背景，不替换模型分类。
- 未提供镜头标记时，仅有一份场景分类可用于单背景；多份分类缺少引用映射时使用中性背景。
- 旧存档中因原地点校验自动降级的演出记录，可用保存的模型字段与引用恢复。显式手工背景选择保留。
- 场景修复仅改变演出数据，不修改剧情、游戏位置、变量命令或人物数据，也不增加模型请求。

相关验证：`avgStructuredSceneRegression.mjs`、`avgSceneRegression.mjs`、`avgRuntimeRepairRegression.mjs`、`avgMissingArtRecoveryRegression.mjs`、`avgSaveRoundtrip.mjs`、`avgPortraitStageRegression.mjs`，以及 TypeScript 和生产构建检查。
