# AVG 场景分类职责边界

2026-10-01，随 1.0.1 修复生效。

场景分类由剧情模型通过结构化字段提供。客户端负责读取字段、建立镜头引用、匹配图片和保存演出快照，不判断模型分类的语义是否正确。

- 保留模型提供的分类字符串，按其空间、地域、场所体系、场所功能等字段匹配素材。素材目录继续使用既有分类词表。
- 不比较镜头地点名称与最终游戏地点来否决分类，不使用地名关键词推断或重新生成分类。
- 新场景字段缺失、类型无法读取、引用不存在或定义重复时，仅对应镜头使用中性背景；其他镜头继续播放。已有绑定的完整地点或场景 ID 可直接复用，不要求重复分类。
- 模型分类没有对应素材时使用中性背景，不替换模型分类。
- 未提供镜头标记时，仅有一份场景分类可用于单背景；多份分类缺少引用映射时使用中性背景。
- 旧存档中因原地点校验自动降级的演出记录，可用保存的模型字段与引用恢复。显式手工背景选择保留。
- 场景修复仅改变演出数据，不修改剧情、游戏位置、变量命令或人物数据，也不增加模型请求。

1.0.2 增加可选的 `场景ID`。`ref` 仍是回合内引用；持久 ID 与已选素材、精确地点别名随演出快照保存。首次匹配固定图片，后续分类不会自动换图，模型提供的新分类字符串仍保留。手工选图可显式覆盖。

已有记录没有 ID 时以 `place:完整地点键` 提供稳定身份。完整地点相同即可复用；地点写法变化必须由模型输出已知 ID 与当前地点明确关联。客户端不猜别名，不把最后镜头与最终游戏环境自动合并。ID 与地点分别指向不同已绑定空间时属于引用结构冲突，仅冲突镜头中性。

普通与酒馆请求都附已绑定场景列表，来源是完整历史而非近期剧情窗口；注入最近使用的最多 80 个身份，明确省略数量。实际复用查询包含保存历史的所有绑定和已声明别名。旧空白回合只在精确身份可确认时恢复，保留已有图片和手工选择。
