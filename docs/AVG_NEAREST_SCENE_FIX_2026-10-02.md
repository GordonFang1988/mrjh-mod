# AVG 缺分类新地点的最后一级选图

用户案例：大理国 / 无量山 / 无量山后山 / 深谷边缘。

## 原因与行为

诊断显示场景图库已加载 2230 张图，请求包含 AVG 协议和历史场景绑定，但回复没有场景表或镜头标记。保存的分类是“空间：未知”。旧实现仅在具体地点包含空间词条或房间别名时进行近似选图；“深谷边缘”未命中，评分前即被空间过滤清空。v1.0.7 的词条兜底因此仍无法覆盖新地名。

现在缺少空间分类且具有具体地点时，先使用相应空间类型；词条未命中或对应候选为空，则进入最后一级候选评分。具体地点与空间分类、素材标签、自然要素匹配，上级场所只提供较弱的参考。同一大地点中明确保存的历史分类若有唯一地域共识，可作为近似选图偏好；不同大地点和有冲突的地域不参与该偏好。

场景原始分类仍为“未知”，查询分类、层级和地域参考单独存入 `fallback`，诊断使用相同参数。背景选择不声明地点别名。已有冻结图、手工选择和同分的稳定选择保持原有规则。没有具体地点、镜头无法映射或身份冲突的情况继续保留原结构边界；显式提供但图库未支持的空间分类维持现有处理。

本案例根据此前明确保存的“西南”地域，在完整图库中选择 `MT027`（西南双溪汇流高山谷），评分 20.625。原场景 ID 与地点保持原样。读档恢复仅在本地图片可读取时应用，不修改正文、游戏命令或此前已有背景。

## 验证方式

- `node scripts/avgNearestSceneRegression.mjs`：可在无本地图包的干净检出中使用小型可携带素材集；有完整 manifest 时自动验证 2230 张场景图。
- 可选参数：用户诊断 JSON 路径、完整 manifest 路径。诊断文件与图片留在本地，不进入提交。
- 覆盖具体地点优先、自然要素评分、同国地域共识、冲突与跨国隔离、源分类保留、缺少同类图的兜底、未映射镜头、冻结与手工选择、48 次连续新地点和 48 次返回、旧空白恢复、图片不可读与重复恢复。
- 相关场景机制、结构化场景、持续绑定、旧图恢复、诊断、饮食场景、开局请求和人物回归共同验证。
- 本地独立浏览器使用真实 `AvgStage`、完整场景 manifest、原生 IndexedDB 图包读取与实际 WebP 字节。用户深谷回合 11 段播放和 12 次连续转场检查背景已解码；修复前后截图及详细报告存于本地 `work/playwright/nearest-scene-2026-10-02/`。

近似匹配改善模型缺字段时的可用性；其图像相似程度依赖图库标签与可用素材，不代表模型提供了这些场景事实。
