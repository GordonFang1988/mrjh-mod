## 修复

旧校验直接搜索全文中的 thinking、说明、命令标签，并把以 JSON 开头的回复整体当作单个 JSON。存在以下误拦截：

1. 已有完整正式说明、命令，但前面的思考漏结束标签，整段拒绝。
2. 说明漏结束标签，后续命令块完整，整段拒绝。
3. 命令字符串中提到标签样例，被误认为真正的未闭合标签。
4. 多条完整 JSON 命令逐行返回，被误认为一个损坏的 JSON。

新增校验只在完整命令块提供明确边界时补齐思考、说明结束标签；不补命令结束标签、不改命令值。已闭合思考内的命令样例不会被当成正式命令。解析时按实际标签边界移除思考，保留字符串中的标签文字。

真实输出长度截断、缺少完整命令块、未闭合 JSON 值、只有思考或没有正式回答仍拒绝。完整的逐行 JSON 命令保持兼容。

世界和变量提示词统一为内部审计、正式回答输出完整说明和命令；思考块可选。变量原有 Step0~Step12 审计项目保留，但不再强制打印每步三条思考。

诊断新增 formatIssue 和 formatRepairs 枚举；解析失败记录 invalid-output，后续应用记录保留修复标记。只记录类别，不导出完整回复、提示词或密钥。
