# 具名立绘与存档美术主题修复

日期：2026-10-03。基线：v1.1.2。发布版本：v1.1.3。

## 原因

用户诊断 `mrjh-diagnostic-v3`（导出 UTC 2026-10-02T16:08:10.103Z）显示：存档主题为 `shuihu-jinpingmei`，甘宝宝 NPC007 年龄 30，自动绑定通用“大院女护卫” RPF1529，本地文件存在。近期绑定中钟灵使用通用少女 YPF051-B，段誉、左子穆也使用通用立绘。主题筛选会排除天龙具名资源。

完整美术包 0.8.0 中，甘宝宝 TF009/TV017/TV018 的年龄范围为 32–45，另外会排除存档中的 30 岁角色。钟灵 TF005/TV009/TV010 的旧标注为 18–23，程序已有兼容校正到 16–23；本次问题还受主题影响，不能仅归因于钟灵年龄。

诊断只提供最新回合甘宝宝的详细年龄。其他人物的实际存档年龄未在本份诊断中确认；回归中的其他年龄为模拟值。

## 实现

- 甘宝宝兼容校正限定三个旧资源 ID、准确角色 key、天龙主题、女性及原始 32–45 范围，解析时改为 30–45。NPC 年龄、安装包原文件和视觉年龄不变；钟灵既有校正保持有效。
- 尊重用户选择的主题，不自动推断或切换故事。具名人物的通用误绑继续使用现有精确身份升级机制。
- 游戏中切换主题时调用已有资源恢复流程，图片确认可读取后更新历史绑定并自动保存。若期间发生读档、重开、新回合、社交变化或再次切换主题，过期结果不会覆盖当前状态。
- 电脑与手机开局第一步增加“本存档美术主题”，确认页显示选择。新局默认通用，不继承上一局；自定义开局方案保留主题。快速重开采用当前存档主题。
- 开局选择在世界生成前应用到游戏设置，并显式传给开场工作流，避免 React 尚未重绘时闭包沿用旧主题。首回合自动存档也显式携带这份设置。原有读档流程继续从各自存档恢复主题。
- 诊断增加其他主题中的同名具名候选、近期最多 20 名人物的年龄/绑定/候选/当前解析结果，仍只采集最近 10 回合，不增加完整历史或 API 正文。

手动选择、生成图和已建立的具名身份保持优先；缺失或无法读取的目标图片不会被记作成功校正。通用人物与年龄边界继续执行原规则。

## 验证

- `node scripts/avgNamedCastCompatibilityRegression.mjs docs/avg-art-production/complete-webp-008/manifest.json`：实际 4676 个立绘的目录；钟灵、甘宝宝、段誉、左子穆、马五德精确 ID；模拟旧绑定校正、幂等、文件缺失/读取失败、手动/生成图保护、年龄/主题/同名歧义边界、近期诊断上限。
- `node scripts/avgZhongLingCompatibilityRegression.mjs docs/avg-art-production/complete-webp-008/manifest.json`：2230 场景/4676 立绘，原始元数据未修改，旧年龄兼容边界和三套钟灵同人变体。
- `node scripts/avgSaveThemeRegression.mjs`：实际会话/世界生成与存档协调代码；只替换数据库及提供者边界。验证新局选定主题、旧闭包覆盖、通用默认、预设往返、不同槽位恢复、自动存档设置快照。
- `avgThemeVariantRegression`、`avgMissingArtRecoveryRegression`、`openingStateRegression` 通过；限定源码范围的 TypeScript 检查及生产构建通过。
- Playwright 使用独立内存浏览器与 localhost:5197 测试，验证桌面确认页和手机开局选择。另在该测试浏览器的隔离数据库中建立模拟水浒旧存档及具名目录，将主题改为天龙，实际页面立即校正五人并生成自动存档；原手动快照保持原主题。使用占位图片，仅证明绑定与保存流程，不代替真实立绘视觉验收。没有调用游戏提供者 API 或写入玩家生产存档。

浏览器证据：`work/regression/avg-theme-mobile-opening.png`、`work/regression/avg-theme-desktop-confirm.png`；模拟切换脚本 `avg-theme-browser-seed.cjs` 与 `avg-theme-browser-verify.cjs` 位于同目录。

## 用户验证

发布后，在旧档 AVG 设置中选择“天龙八部”，检查人物造型及自动存档，再重新读取该自动存档确认主题与绑定保持。无需重新导入旧完整包。人物实际年龄如果仍超出其他具名立绘的合理范围，可从新的近期人物诊断继续定位，不能无依据全局取消年龄校验。
